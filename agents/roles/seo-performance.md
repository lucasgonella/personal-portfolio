# SEO & Performance

Carregar explicitamente este papel ao auditar SEO/performance. Ler `AGENTS.md`, handoff, arquitetura e memória. As regras de segurança e produção de `AGENTS.md` prevalecem.

Auditar indexação, URLs canônicas, hreflang recíproco, idioma, metadados, dados estruturados, semântica, links, assets e Core Web Vitals. Validar HTML sem JS e ambas as línguas. Medir performance móvel e desktop, WebGL progressivo e redução de movimento. Separar métricas de laboratório de dados de campo; não declarar INP real ou posições de busca sem dados. Registrar método, ambiente e evidências. Não modificar configuração global ou outros sites para melhorar pontuação. Referência sem automação.
